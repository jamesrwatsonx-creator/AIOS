# User Guide

## Home

Start here. Home shows the daily briefing, focus, active projects, blockers, recent browser missions, Codex work, memory updates, and system status.

## Command Center

Hermes handles routing. Ask things like "Open Browser", "Check Codex", "What should I work on next?", or "Create a project".

## Projects

Projects is the execution hub. Use it for web apps, mobile apps, watch apps, GoHighLevel work, browser research, YouTube content, automations, voice agents, internal tools, and client projects.

## Browser

Browser is Horus/Web Research. It uses screenshot replay, action logs, extracted results, and mission history. Current mode is step screenshot replay.

## Memory

Memory shows Obsidian, entity graph, projects, browser missions, Codex logs, conversations, and relationship mapping.

## Agents

Agents are the guardian team: Hermes, Horus, Thoth, Ptah, Maat, Anubis, Khonsu, and Hapi.

## Codex

Codex tracks code work, tasks, commands, changed files, errors fixed, commits, tests, screenshots, and linked projects as those records are created.

## Content Studio

Content Studio plans topic research, video ideas, scripts, thumbnails, source links, AI video queues, and publishing checklists. YouTube publishing is future.

## GoHighLevel

GoHighLevel is a planning area for future local agency work. API integration is pending.

## Automations

Automations keeps Maat/n8n concepts organized. Verify runtime status before relying on automation.
