# AIOS User Guide

AIOS is organized around a simple operator workflow: decide what matters today, route work through the right section, save what happened, and review the next action.

## Home

Home is the daily briefing. It shows current briefing, focus, active projects, blockers, suggested next actions, recent browser missions, recent Codex work, recent memory updates, and system status.

## Command Center

Command Center is Hermes. Use it for plain English requests such as Build a mobile app, Research local businesses, Create a GoHighLevel project, Start a YouTube video idea, Check what Codex did, Open Browser, Show blockers, and What should I work on next.

## Projects

Projects is the execution hub for web apps, mobile apps, watch apps, browser research, YouTube content, GoHighLevel work, automations, voice agents, internal tools, and client projects.

A strong project record should have status, owner or agent, tasks, milestones, browser missions, Codex work, Obsidian notes, related memories, activity history, and next action.

## Browser

Browser is Horus Web Research. Use it to run or review browser missions. Current verified mode is step screenshot replay. Future mode is live streaming.

## Memory

Memory is the simplified surface over Memory Nexus. Use it to review Obsidian status, entity graph summary, recent memories, browser missions, Codex logs, project notes, conversations, and relationships.

## Agents

Agents are the guardian team in plain English: Hermes for Command Center, Horus for Web Research, Thoth for Research and Knowledge, Ptah for Build Studio, Maat for Automations, Anubis for Review and Security, Khonsu for Calendar and Timing, and Hapi for System Health.

## Codex

Codex tracks engineering work: current task, completed tasks, files changed, commands run, errors fixed, commits, browser tests, build results, screenshots, linked project, Obsidian notes, entity, and activity.

## Automations

Automations is the Maat surface for scheduled and recurring operations. It should show scheduled tasks, recurring research, overnight workflows, n8n status, cloud status, pending automations, completed automations, and failure logs.

Current status: n8n runtime must be verified locally. Cloud server and 24/7 mode are future.

## Content Studio

Content Studio is for topic research, video ideas, scripts, thumbnail ideas, source links, AI video queue, publishing checklist, content calendar, browser research missions, and Obsidian content notes. YouTube publishing API is future.

## GoHighLevel

GoHighLevel is the future agency operations area for client projects, funnels, voice agents, missed-call systems, GEO and AI visibility audits, review automations, SMS and email workflows, appointment systems, browser research missions, and Codex build logs. API integration is pending unless configured and verified.

## Activity

Activity shows work across AIOS: project updates, memory writes, browser missions, Codex work, system events, and agent actions.

## Settings

Settings is for system status and configuration visibility. It should never expose raw secrets.
