# Repository Map

- app/: Next.js routes.
- app/api/: local API routes for Hermes, Memory Nexus, Browser sessions, and Obsidian writes.
- components/: UI, layout, browser, memory, projects, agents, Codex, content, GoHighLevel, and operator sections.
- lib/: navigation, persistence, entity graph, browser routing, Obsidian client, Hermes command routing, guardians, memory engines, and system paths.
- docs/: planning, architecture, user guide, and operating documentation.
- scripts/: local supporting scripts such as Hermes voice server.
- public/: static assets.
- reference/: reference images and assets.
